# 📌 Overview

The final part of this project focuses on integrating the Presentation Tier, Application Tier, and Data Tier into a complete 3-tier web application. 

In this phase, the frontend, API, and database are connected to enable seamless communication between each layer, allowing users to retrieve data through a fully functional cloud-based application.
